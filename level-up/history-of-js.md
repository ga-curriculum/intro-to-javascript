# History of JavaScript

JavaScript is a high-level, client-side programming language used for web development. While HTML provides the structure of a website, and CSS defines its appearance, Javascript is the language that makes a site dynamic and interactive.

Javascript emerged during the browser wars of the 1990s. Developers at Netscape were looking for features that could make them more competitive with Microsoft’s Internet Explorer.

At the time, websites were largely static. Implementing some sort of language that could be executed client-side would make websites far more dynamic.

In 1995, Netscape tasked Brendan Eich with developing a programming language that could run inside their browser. To meet the planned release date of the Navigator 2.0, Eich created the first iteration of this new language in just 10 days. The new language was dubbed Javascript as a marketing ploy to associate it with Java.

In 1997, Netscape reached out to the European Computer Manufacturers Association (ECMA) to assist in the standardization of Javascript. As a result of this standardization effort, Javascript works in any browser. By the 2000s, several big tech companies had adopted Javascript, further fueling its popularity.

Today Javascript is one of the most popular and in demand programming languages around. Alongside HTML and CSS, it is one of the foundational technologies of the modern web.
