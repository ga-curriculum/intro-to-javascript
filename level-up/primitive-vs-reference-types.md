# ![Intro to JavaScript - Level Up - Primitive vs. Reference Types](./assets/hero-primitive-vs-reference.png)

**Learning objective:** By the end of this lesson, students will understand the fundamental differences between primitive and reference types in JavaScript, including size, mutability, and assignment behavior.

Some of the key differences between primitive and reference types in JavaScript are:

- **Size**: Primitive types are stored directly in memory and have a fixed size. On the other hand, reference types store a reference to an object in memory, so their size can vary depending on the object's size.
- **Mutability**: Primitive values are immutable, meaning they cannot be changed once created. On the other hand, reference values are mutable, meaning that they can be changed once made.
- **Assignment**: When you assign a primitive value to a variable, a copy of the value is stored in the variable. When you assign a reference value to a variable, a reference to the object is stored in the variable.
