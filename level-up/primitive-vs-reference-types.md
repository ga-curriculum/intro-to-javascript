# Intro to JavaScript - Level Up - Primitive vs. Reference Types

![Hero image](./assets/hero.png)

As we learned in the [Primitive Data Types](../primitive-data-types/README.md) and [Reference Data Types](../reference-data-types/README.md) lectures, primitive types are JavaScript data types that are stored directly in memory, and referece types store a reference to an object in memory. 

## Differences between primitive and reference types

Some of the key differences between primitive and reference types in JavaScript are:

  - **Size**: Primitive types are stored directly in memory, so they have a fixed size. Reference types, on the other hand, store a reference to an object in memory, so their size can vary depending on the size of the object.

  - **Mutability**: Primitive values are immutable, meaning that they cannot be changed once they are created. Reference values, on the other hand, are mutable, meaning that they can be changed once they are created.

  - **Assignment**: When you assign a primitive value to a variable, a copy of the value is stored in the variable. When you assign a reference value to a variable, a reference to the object is stored in the variable.
