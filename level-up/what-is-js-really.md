# What is JavaScript *really*?

As we know, JavaScript is a text-based programming language used both on the front-end and back-end of web development. It adds interactivity to websites and web applications, allowing users to interact with elements on the page and perform tasks such as submitting forms, playing games, and watching videos. 

## But what is JavaScript *really*?

Javascript is a dynamic, interpreted, and weakly typed language, built with the purpose of running in hosted environments.
