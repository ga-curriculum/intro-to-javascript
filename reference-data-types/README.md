# Intro to JavaScript - Reference Data Types

![Hero image](./assets/hero.png)

**Learning objective:** By the end of this lesson, students will know of the reference data type in JavaScript.

The seven data types we've looked at thus far are classified as primitive or value data types because they can hold only a single value.

Most programming languages also have complex or reference data types to hold more complex data structures.

JavaScript only has one reference type - the ***object***. That being said, there are several types of objects in JavaScript:

- Array
- Object
- Function
- RegEx
- Date
